# 플립 스크린

모니터 전체나 일부에 **플립 시계·날짜·달력·디데이·행선지 안내판·내 문구·그림**을 띄우는 윈도우 앱입니다.
이 저장소는 설치 파일을 내려받는 곳입니다.

## 내려받기

[**최신 버전 내려받기**](https://github.com/ykyyyky55-cmd/flip-screen-releases/releases/latest) → `FlipScreen-Setup-버전.exe` 를 받아 실행하세요.

- 윈도우 10·11 (64비트)
- 설치할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누르세요. 아직 코드 서명 인증서가 없어서 나오는 안내입니다.
- 한 번 설치하면 새 버전은 앱이 알아서 받아 두고, 다음에 켤 때 적용됩니다.

## 할 수 있는 것

- 플립 화면을 여러 개 만들어 모니터마다 원하는 자리에 둡니다.
  - 범위: 모니터 전체 / 일부분
  - 놓는 곳: 바탕화면 아이콘 뒤(배경화면처럼) · 다른 창들 뒤 · 항상 맨 위
- 플립칸을 원하는 만큼 넣고 크기·순서·이름표를 정합니다.
  - 시계(세계 시간대) · 날짜 · 달력 · 디데이 · 내 문구 · 행선지(출발) 안내판 · 그림
- 테마 7가지, 색·글꼴·배경(투명/색/그림), 모서리·간격, 넘김 속도·촤라락 넘김·넘김 소리

설정은 `%APPDATA%\플립 스크린` 에 저장되어 업데이트해도 그대로 남습니다.
