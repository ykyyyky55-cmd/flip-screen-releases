# 플립 스크린

모니터 전체나 일부에 **플립 시계·날짜·달력·디데이·행선지 안내판·내 문구·그림**을 띄우는 윈도우 앱입니다.
이 저장소는 설치 파일을 내려받는 곳입니다.

## 내려받기

[**최신 버전 내려받기**](https://github.com/ykyyyky55-cmd/flip-screen-releases/releases/latest) → `FlipScreen-Setup-버전.exe` 를 받아 실행하세요.

- 윈도우 10·11 (64비트)
- 설치할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누르세요. 아직 코드 서명 인증서가 없어서 나오는 안내입니다.
- 한 번 설치하면 새 버전은 앱이 알아서 받아 두고, 다음에 켤 때 적용됩니다.

## 할 수 있는 것

- 플립 화면을 여러 개 만들어 모니터마다 원하는 자리에 둡니다.
  - 범위: 모니터 전체 / 일부분
  - 놓는 곳: 바탕화면 아이콘 뒤(배경화면처럼) · 다른 창들 뒤 · 항상 맨 위
- 플립칸을 원하는 만큼 넣고 크기·순서·이름표를 정합니다.
  - 시계(세계 시간대) · 날짜 · 달력 · 디데이 · 타이머 · 내 문구 · 행선지(출발) 안내판 · 그림
  - **사진 모자이크**: 화면 전체를 사진으로 채우고 조각조각 여러 번 돌며 다음 사진으로
- **음성 명령**: 단축키를 누르고 말하거나 "플립아"로 부르기. 인식은 이 PC 안에서만(목소리가 밖으로 나가지 않음)
  - "회의 중이라고 띄워줘", "다음 사진", "타이머 5분", "12월 25일 크리스마스 디데이 만들어줘", "다음 주 수요일 치과 달력에 표시해줘"
- 테마 7가지, 색·글꼴·배경(투명/색/그림), 모서리·간격, 넘김 속도·촤라락 넘김·넘김 소리(부드럽게·종이·나무·딸깍)

## 무료와 Pro

| | 무료 | Pro |
|---|---|---|
| 플립 화면 | 2개 | 제한 없음 |
| 칸 | 시계·날짜·달력·디데이·타이머·내 문구 | + 행선지 안내판·그림·사진 모자이크 |
| 시간대 | 이 컴퓨터 시간 | 세계 시간대 |
| 배경 | 투명·색 | + 그림 |
| 음성 명령 | — | ✓ |

Pro 는 설정 창 왼쪽 아래 'Pro 정품 등록'에 Pro 키를 넣으면 켜집니다.

설정은 `%APPDATA%\플립 스크린` 에 저장되어 업데이트해도 그대로 남습니다.
